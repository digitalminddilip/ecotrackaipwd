Problem Statement

The Urban Sanitation Crisis: Why Current Systems Fail

1. Citizen Reporting Friction
  • Cumbersome Portals: Requires lengthy forms, OTP delays, or desktop access.
  • No Feedback Loop: Citizens submit reports into a black hole and lose faith.
  • Accessibility Barrier: Non-tech-savvy or non-literate citizens cannot type descriptions.
2. Municipal Operational Blindspots
  • No Spatial Intelligence: Authorities lack real-time GIS density clustering.
  • Manual Triage Bottleneck: Staff waste hours sorting duplicate or irrelevant photos.
  • Reactive Dispatch: Trucks deployed without route optimization, wasting fuel and time.
3. The Verification Gap (Ghost Cleanups)
  • No Visual Proof: Contractors mark tasks 'Done' without verifiable evidence.
  • Supervisory Overload: Physical inspection of hundreds of daily sites is impossible.
  • Public Fund Leakage: Millions paid for unperformed or partial waste pickups.

AI Innovations

Under the Hood: Three Core AI Innovations

1. Dual-Layer Multimodal Vision
  • Cloud AI: Google Gemini Vision API for rich scene understanding & semantic hazard detection.
  • Edge Fallback: 96-D perceptual model (Color Histograms + RGB/HSV moments) ensures 100% offline availability.
  • Material Precision: Identifies Plastic, Biodegradable, Glass, Metal, Paper, Cardboard.
2. Conversational Voice AI (Hinglish)
  • Bilingual NLU: Understands native English and natural Hinglish conversational queries.
  • Zero-Typing Accessibility: Non-literate citizens simply speak aloud to file civic complaints.
  • Civic Guidance: Answers waste segregation questions ('Kachra kahan daalein?') with instant voice audio.
3. Computer Vision Verification Engine
  • Before-and-After Analysis: Compares structural landmarks between original report and cleanup evidence.
  • 75%+ Threshold: Requires background invariant matching while verifying waste clearance.
  • Zero Fraud: Rejects fake photos taken at different locations or downloaded from the web.

System Architecture

Engineering Architecture: High-Concurrency & Zero-Cost Cloud

🏛️ Technology Stack Matrix
  • Backend: FastAPI (Python 3.12+) with Uvicorn Async ASGI Engine.
  • Database: High-concurrency SQLite / PostgreSQL with spatial indexes.
  • AI Pipeline: Google Gemini 1.5/2.0 API + 96-D NumPy Perceptual Model.
  • GIS Mapping: Leaflet.js + OpenStreetMap + Google Geolocation / Geocoding.
  • Security: JWT (HS256) + Bcrypt Password Hashing + OAuth 2.0 + OTP.
  • Frontend: Ultra-lightweight Vanilla JS, HTML5, CSS3 (zero bundle bloat).
⚡ Scalable Cloud-Native Deployment
  • Zero-Cost $0 Production Stack: Configured to run completely free across Render (backend) and Vercel (frontend).
  • High Concurrency & Low Latency: Asynchronous non-blocking event loop handles thousands of concurrent civic alerts effortlessly.
  • Containerized Microservices: Multi-platform Docker containerization (`docker-compose.yml`) for instant 1-click cloud deployment.
  • Resilient Self-Healing Architecture: Automated systemd process supervision and health-check monitoring for continuous 24/7 uptime.
